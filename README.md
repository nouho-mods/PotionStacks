# Potion Stacks

Potion Stacks is a Minecraft mod that allows players to stack up to 16 potions, making potion management easier and more convenient.

## Features
- Potions now stack up to 16
- Works with modded potions
- No new items or blocks

## Installation
1. Download the mod JAR from [Modrinth](https://modrinth.com/mod/potion-stacks) or your preferred source
2. Place the JAR file in your Minecraft `mods` folder
4. Launch Minecraft with the NeoForged mod loader

## Compatibility
- Compatible with most mods that add new potions
- Required on both server and client
